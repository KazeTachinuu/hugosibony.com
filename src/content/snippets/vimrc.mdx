## Installation

```shell
curl -fsSL https://raw.githubusercontent.com/KazeTachinuu/epita-ing1-setup/master/setup.sh | sh
```

## Exam Config

Exam machines have no AFS and no network, so nothing installs: memorize these
3 lines. Line 1 must come first, since writing any `~/.vimrc` disables the
built-in `defaults.vim`.
