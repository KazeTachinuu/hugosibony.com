Patterns I copy into every installer script. Copy-paste, not a library:
install scripts should stay single-file and curl-able.

## Marker output

Colors only on a TTY, honoring `NO_COLOR` and `TERM=dumb`; piped output stays
plain with the markers intact.

```bash
# [*] info  [+] did something  [=] already converged  [-] warn, kept going  [x] fatal
if [ -t 1 ] && [ -z "${NO_COLOR:-}" ] && [ "${TERM:-}" != dumb ]; then
    B='\033[1;34m' G='\033[1;32m' Y='\033[1;33m' R='\033[31m' D='\033[2m' N='\033[0m'
else
    B= G= Y= R= D= N=
fi
hdr()  { printf "${B}[*]${N} %s\n" "$1"; }
ok()   { printf "${G}[+]${N} %s\n" "$1"; }
skip() { printf "${D}[=] %s${N}\n" "$1"; }
warn() { printf "${Y}[-]${N} %s\n" "$1" >&2; }
die()  { printf "${R}[x]${N} %s\n" "$1" >&2; exit 1; }
```

## Idempotent symlink

Zero work when converged, one backup for a pre-existing real file, never a
dangling link. A rerun that prints only `[=]` lines is visual proof of
idempotency: check desired state, do not remember past actions.

```bash
link() {
    src="$1" dst="$2"
    [ -e "$src" ] || { warn "$src missing, skipped"; return 0; }
    [ "$(readlink "$dst" 2>/dev/null)" = "$src" ] && { skip "$dst"; return 0; }
    if [ -e "$dst" ] && [ ! -L "$dst" ]; then
        mv "$dst" "$dst.backup"
        warn "kept old file as $dst.backup"
    fi
    mkdir -p "$(dirname "$dst")"
    ln -sfn "$src" "$dst"
    ok "linked $dst"
}
```

## Pinned, checksummed fetch

HTTPS only with no protocol downgrade, pinned commit or tag (never a mutable
branch), sha256 before use, atomic staging, and warn-and-continue so one
failed optional tool never kills the install.

```bash
CURL="curl -fsSL --proto =https --tlsv1.2 --retry 3"
verified() { printf '%s  %s\n' "$2" "$1" | sha256sum -c - >/dev/null 2>&1; }
trap 'rm -f .new.*' EXIT

# fetch_pinned <name> <url-at-pinned-ref> <sha256> <dest>
fetch_pinned() {
    [ -e "$4" ] && { skip "$1: already installed"; return 0; }
    if $CURL -o ".new.$1" "$2" && verified ".new.$1" "$3"; then
        mv ".new.$1" "$4" && chmod +x "$4"
        ok "$1: installed"
    else
        warn "$1: fetch or checksum failed, skipped"
    fi
}
```

Release flow for the pinning side: commit, pin to that commit, and verify the
raw URL serves the pinned bytes before pushing the installer that trusts it.

```bash
PIN=$(git rev-parse HEAD)
SHA=$(sha256sum tool.sh | cut -d' ' -f1)
curl -fsSL "$RAW/$PIN/tool.sh" | sha256sum | grep -q "$SHA"
```

## Progress without theater

Instant steps get a counter, never an animated bar. Slow steps reuse the
tool's native progress (`git --progress`, `curl -#`), which already knows
totals and ETA better than you do. Progress goes to the TTY only.

```bash
TOTAL=3 N=0    # keep TOTAL equal to the number of steps
step() { N=$((N + 1)); ok "[$N/$TOTAL] $1"; }

# single-line ticker for loops over many items; cleans up after itself
tick()    { [ -t 1 ] && printf "\r    %2d/%d %s\033[K" "$1" "$2" "$3" || true; }
tickend() { [ -t 1 ] && printf '\r\033[K' || true; }

# curl: progress bar on a TTY, silent when piped (stderr carries the bar)
if [ -t 2 ]; then CURL="curl -f#L"; else CURL="curl -fsSL"; fi
```
