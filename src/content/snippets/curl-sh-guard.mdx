---
title: "curl | sh truncation guard"
description: "Wrap installers in main() so a truncated download runs nothing"
category: "Shell"
date: 2026-08-13T13:00:00+02:00
updated: 2026-08-16
---

`curl | sh` executes the stream as it arrives, so a dropped connection runs
half a script. Fix (used by rustup and Homebrew): put everything in one
function, called on the last line. A truncated download defines a broken
function, hits a syntax error, and executes nothing.

```bash
main() {
    ...entire script...
}
main "$@"
```

Function definitions and variable assignments can stay top-level; they have
no side effects if the tail is missing.
